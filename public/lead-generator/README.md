# 慧营通 · 电话线索数据生成软件

这是一个无需安装依赖、双击即可使用的本地网页软件。

## 使用方法

1. 双击打开 `index.html`。
2. 在蓝色“线索数据生成台”设置店铺名称、开始时间、结束时间和线索数量。
3. 点击“生成数据”，软件会随机生成客户手机号、来电时间、线索 ID、渠道、录音及通话状态。
4. “高级生成设置”可限制每天的生成时段，设置均匀、近期优先、工作日优先或自定义逐日日期权重，并精确控制三种通话状态比例。
5. 可按渠道、线索 ID、手机号和起止日期筛选；日期只显示年月日，不显示具体时分。
6. “查看明文线索”可切换完整电话；“下载线索”可导出 CSV。
7. 点击“导出为图片”可保存当前后台页面为 PNG，图片会自动隐藏蓝色“线索数据生成台”，其他内容保持显示。
8. 列表支持 10/20/50/100 条每页、翻页和指定页跳转。

数据会自动保存在当前浏览器本地，刷新页面不会丢失。单次支持生成 1–500 条。
